# バドミントン日程調整 Bot — 使い方ガイド

**対象**: グループメンバー全員（スマホ操作に慣れていない方もOK）

---

## このBotでできること

体育館の個人開放（バドミントン）の日程調整を **LINE だけで完結** できます。

| 今まで | このBotを使うと |
|:--|:--|
| LINEで「○○日どう？」と聞いて回る | Botが自動でフォームを配信 |
| 返信が来るまで待つ | 誰が回答済みかいつでも確認できる |
| 手動で「4人集まった！」と連絡 | Botが自動で「4人揃いました」と通知 |

---

## 使い方の流れ

### ステップ1：グループに招待する（最初だけ）

Botをグループトークに招待するだけで準備完了です。

> Bot をグループに招待した時点で、グループ全員が自動でメンバー登録されます。追加でやることはありません。

---

### ステップ2：日程調整フォームを受け取る

体育館のスケジュールが更新されると、Bot が自動でグループに通知を送ります。

```
【日程調整】参加できる日時を回答してください（3件）
 ┌────────────────────┐
 │ バドミントン日程調整    │
 │                        │
 │ 直近のスケジュールが届き │
 │ ました！参加できる日時を │
 │ 回答してください。       │
 │                        │
 │ [回答する] [回答状況を見る] │
 └────────────────────┘
```

---

### ステップ3：「回答する」をタップして回答

「回答する」ボタンをタップするとフォームが開きます（LINE アプリの中で開くので、別のアプリに切り替わりません）。

**フォームの操作方法：**

1. 日付と時間帯が表（グリッド）で並んでいます
2. 各マスをタップして回答を選んでください

| 表示 | 意味 |
|:--:|:--|
| ○ | 参加できる |
| △ | たぶん参加できる（仮OK） |
| × | 参加できない |

3. 全マスを選んだら「送信する」ボタンをタップして完了

> **ポイント**: 途中で閉じても大丈夫です。再度「回答する」をタップすると前の回答が残っています。

---

### ステップ4：「回答状況を見る」で確認

「回答状況を見る」ボタンをタップすると、誰がもう回答したか一覧で確認できます。

---

### ステップ5：Botから通知が届く

#### 4人以上集まったとき（即時通知）

誰かが回答して4人以上集まるスロットが出た時点で、すぐにグループへ通知が来ます。

```
✅ 4人以上集まるスロットがあります！
5/20（火）18:00〜20:00：○4人 / △1人
```

#### 全員が回答し終わったとき（最終結果）

全員の回答が揃ったら、Bot が自動で集計してグループに送ります。

```
【集計結果】
5/20（火）18:00〜20:00：○3人 / △1人 → 参加可能4人 ✅
5/22（木）14:00〜16:00：○2人 / △0人 → 参加可能2人 ❌
```

---

### リマインドが届いたとき

回答が済んでいない場合、Bot から個別にリマインドが届きます。届いたら「回答する」をタップして回答をお願いします。

---

## よくある質問

**Q. Bot を友達追加しないといけないの？**
A. グループに招待するだけでOKです。個別に友達追加しなくても使えます。

**Q. 途中で回答を変えられる？**
A. 「回答する」を再びタップすると、回答を上書きできます。

**Q. スケジュールはどこから来てるの？**
A. 体育館の公式サイトから Bot が毎朝自動で取得しています。手動での入力は不要です。

**Q. グループに招待後、新たに参加したメンバーはどうなる？**
A. グループに参加した時点で自動でメンバー登録されます。
